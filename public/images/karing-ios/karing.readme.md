karing 使用了魔改版的 singbox 内核,支持xray 的 xhttp 协议,推荐使用. 

几乎兼容本站的全部节点.

1.png : 下载地址是: https://apps.apple.com/us/app/karing/id6472431552

2.png: 添加订阅 点击首页的 添加配置 
2-1.png: 选择添加配置链接 改方案就是  添加机场 订阅地址 
2-2.png : 填入订阅地址并添加订阅规则后, 保存
3.png: 点击 图标 开启代理, karing 会自动选择延迟最低点节点使用. 
3-1.png : 你也可以自定义选择的服务器. 在选择之前记得批量测试节点的延迟
4.png : 记得在 karing 设置中将 ipv6 disable 关闭, 这样你可以多使用 本站一半的节点(ipv6 节点).
