v2rayA 使用教程（Debian/Ubuntu）

网页控制台客户端，适合服务器与无桌面环境，透明代理一键开启。

1安装 v2rayA

通过官方软件源在 Debian / Ubuntu 上安装 v2rayA 与 Xray 内核。

1.1添加公钥

wget -qO - https://apt.v2raya.org/key/public-key.asc | sudo tee /etc/apt/keyrings/v2raya.asc

1.2添加 v2rayA 软件源

echo "deb [signed-by=/etc/apt/keyrings/v2raya.asc] https://apt.v2raya.org/ v2raya main" | sudo tee /etc/apt/sources.list.d/v2raya.list
sudo apt update

1.3安装 v2rayA

sudo apt install v2raya xray

2启动 v2rayA

启动服务并设置开机自启（v1.5 起默认不再自动启动）。

2.1启动服务

sudo systemctl start v2raya.service
💡 从 1.5 版本开始不再默认为用户启动 v2rayA 及设置开机自动，需手动执行以下命令。

2.2设置开机自启

sudo systemctl enable v2raya.service

启动后在浏览器打开 http://localhost:2017 访问 v2rayA 控制台。

⚠️ 如通过 2017 端口无法访问 UI，请检查服务是否已启动。

3基本使用

创建账号 → 导入订阅 → 连接节点 → 启动服务 → 配置代理。

3.1创建账号

第一次进入页面时，需要创建一个管理员账号，请妥善保管用户名密码；如遗忘，可使用命令重置：

sudo v2raya --reset-password

3.2导入节点

点击「导入」，支持节点链接、订阅链接、扫描二维码和批量导入等方式。推荐直接粘贴本站 订阅管理 页面的订阅地址，一键导入全部节点。

3.3连接节点并启动服务

导入成功后节点显示在 SERVER 或新标签中，切换到该标签页，选择一个或多个节点连接。

💡 不建议选择过多节点，6 个以内为佳。截至 2021-08，xray 尚未支持基于观测的负载均衡，多节点负载均衡为 v2ray-core 独有。

未启动服务时连接的节点呈柚红色；点击左上角按钮启动服务后，节点变为蓝色且图标显示运行中，代表服务启动成功。

3.4配置代理

默认情况下 v2rayA 通过内核开放 20170 (socks5)、20171 (http)、20172 (带分流规则 http) 端口，三种使用方式：

  • 透明代理（推荐）：设置中选择透明代理的分流与实现方式后保存，可为几乎所有程序提供代理，路由器部署同理；
  • 系统代理：为主动支持代理设置的程序提供代理，位置因桌面环境而异；
  • SwitchyOmega 等浏览器插件：为浏览器提供代理。
💡 如需为局域网其他机器提供代理，请在设置中打开「局域网共享」，并检查防火墙开放情况。
