1安装 v2rayN

下载 deb 安装包安装（图形界面双击 / 命令行 dpkg 两种方式）。

1.1下载并安装

👉 本站下载 v2rayN (Ubuntu/Debian) deb 安装包

下载后双击 deb 安装包，进入安装界面，点击 install/安装。

1.2旧版 Ubuntu 用 dpkg 安装

如果旧版 Ubuntu 无法出现安装界面，请进入 deb 安装包所在目录，打开 Terminal 输入：

sudo dpkg -i v2rayN-linux-64.deb

1.3安装完成

安装后，会在所有程序中显示 v2rayN 图标。

2通过订阅获取节点

添加订阅分组并更新，获取全部节点。

2.1添加订阅

打开 v2rayN → 点击 订阅分组 → 添加订阅 → 别名填写本站名字 → 可选地址填写在订阅管理获取到的订阅地址 → 确定。

2.2更新订阅

v2rayN → 点击本站的分组 → 订阅分组 → 更新当前订阅(不通过代理)；或方案二：订阅分组 → 更新全部订阅(不通过代理)。

2.3节点列表

订阅成功即可看到所有的节点。

⚠️ 如未看到节点列表，请提供截屏并联系管理员获取技术支持。

3使用代理

设为活动服务器并开启系统代理，验证上网。

3.1设为活动服务器并开启系统代理

选择一个节点 → 右键点击 → 设为活动服务器（或选中节点按键盘 Enter 键自动激活）。

设置代理：v2rayN 软件界面下方，把「清除系统代理」修改为 自动配置系统代理。

3.2验证上网

上述配置完成后，打开浏览器访问 google.com，可以在 v2rayN 软件界面看到 google.com (proxy) 类日志输出，即节点可用。

如果节点不可用：请尝试切换其他节点后再次访问；如果多个节点不可用，请提供节点地址和报错截屏提交工单。
