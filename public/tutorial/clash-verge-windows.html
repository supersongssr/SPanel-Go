Clash Verge 使用教程

适用于 Windows 系统。安装、导入订阅、开启代理，三步即可开始科学上网。

1安装 Clash Verge 软件

Clash Verge 与绿色版软件不同，需要先安装才能使用。

步骤运行安装程序

点击下载好的安装程序进行安装，一路下一步即可完成安装。

💡 Clash Verge 需要安装后才能使用，请耐心等待安装完成。

2导入订阅，获取节点

新安装的用户需要先导入订阅地址，才能获取节点。

2.1点击导入订阅

新安装的用户，需要点击 导入订阅，从订阅中获取节点。

2.2输入订阅地址并导入

在弹出的窗口中输入您的 订阅地址，然后点击 导入 即可。

⚠️ 如果出现报错，请检查订阅地址是否填写正确、订阅是否正常可用。

2.3确认订阅导入成功

订阅导入成功后，会显示如图所示的内容，表示节点已经成功获取。

3开启代理，开始上网

Clash 类软件会自动管理节点，使用非常简单。

步骤首页开启代理

Clash 类软件不需要手动测试节点延迟——Clash 会自动测试节点延迟，您只需点击首页的 开启 代理即可。

✅ 开启代理后，即可正常访问 Google、YouTube 等网站。这就是 Clash Verge 在 Windows 上的完整图文教程。
