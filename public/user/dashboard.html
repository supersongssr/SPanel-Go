客户端快捷配置与连接订阅教程

专属客户端配置订阅链接

Windows v2rayN 使用步骤：

  1. 点击下载软件：v2rayN 电脑正式版。下载后解压缩，运行其中的 V2rayN.exe。
  2. 在软件顶部点击 “订阅分组” -> “订阅分组设置” -> 点击 “添加”。
  3. 在配置窗内填写：别名随意(例如：SPanel)，可选地址填入上面的专属订阅链接，勾选“启用订阅”，保存关闭。
  4. 再次点击顶部 “订阅分组” -> “更新订阅(不通过代理)”，稍等片刻，主界面将展示所有的全球加速节点。
  5. 任意选择一个物理节点，右键点击 -> 设为活动服务器。
  6. 在 Windows 桌面任务栏右下角找到 v2rayN 蓝色小图标，右键 -> “系统代理” -> 设为 “自动配置系统代理”，并在 “路由” 中设为 “绕过大陆”。即可完美上网。

Windows Clash Verge 使用步骤：

  1. 点击下载软件：Clash Verge 电脑安装包。安装并运行 Clash Verge。
  2. 在软件左侧菜单选择 “Profiles”，在输入框中贴入上面的专属订阅链接，点击 “Download”。
  3. 下载完成后，单击选中刚刚生成的 Profile 使其亮起激活。
  4. 在左侧菜单栏选择 “Proxies”，在这里您可以为不同的地理组自由勾选加速线路。
  5. 在左侧菜单栏选择 “Settings”，勾选开启 “System Proxy” (系统代理) 与 “Start with Windows” (开机自启)。即可成功启用代理！

Android v2rayNG 手机客户端使用步骤：

  1. 点击下载软件安装包：v2rayNG 安卓安装包，下载后完成在手机上的安装。
  2. 打开 v2rayNG 客户端，点击左上角三横杠菜单，进入 “订阅设置”，点击右上角 “+” 按钮。
  3. 输入备注 (如：SPanel)，并在地址一栏贴入上面的专属订阅链接，点击右上角对勾保存。
  4. 返回主界面，点击右上角三个点，选择 “更新订阅”。全球节点列表将瞬间同步完成。
  5. 选中一个想要连通的加速节点 (左侧显示绿条表示选中)。
  6. 点击右下角圆形的 “V” 字连接按钮。首次开启会弹出 VPN 权限请求，请点击 “允许 / 确定”，连接成功后即可流畅访问。

Linux Debian v2rayA 开源服务使用步骤：

  1. 安装并配置 v2rayA 系统守护服务：
    wget -qO - https://apt.v2raya.mzz.pub/key/public-key.asc | sudo apt-key add -
    echo "deb https://apt.v2raya.mzz.pub/ v2raya main" | sudo tee /etc/apt/sources.list.d/v2raya.list
    sudo apt update && sudo apt install v2raya -y
  2. 启动 v2rayA 后台并设为自启动：sudo systemctl enable v2raya --now
  3. 打开本机浏览器控制台：http://localhost:2017。
  4. 在界面点击 “Import”，将上面的专属订阅链接导入并保存更新。在列表中选择物理加速节点并启动服务即可！
