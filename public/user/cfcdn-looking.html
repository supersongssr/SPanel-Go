什么是优选 IP？

Cloudflare 优选 IP 是指在 Cloudflare CDN 节点中经实测延迟低、速率表现优异的 IP 地址。使用优选 IP 建立连接可显著提升链路质量与传输速度。优选 IP 可在 安全设置 中进行配置。
